# 🍕 Додо Пицца — Система автоматизации заказов

Веб-приложение для автоматизации приема и обработки заказов доставки пиццы.

## Функционал

### Для клиентов

- Каталог с фильтром по категориям
- Корзина
- Оформление заказа с выбором пункта выдачи
- Отслеживание статуса заказа
- История заказов

### Для сотрудников кухни

- Режим кухни с фильтрацией по статусам
- Изменение статуса заказа

### Для администраторов

- Управление товарами
- Управление пунктами выдачи
- Просмотр всех заказов
- Отчеты

## Запуск

```bash
npm install -g json-server
json-server --watch db.json --port 3000
```
